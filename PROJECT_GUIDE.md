# Project Guide: CyberAware Pro

## What to demonstrate
1. Open the app and explain the purpose.
2. Submit a sample pre-test using a fictional ID like DEMO01.
3. Show the overall score, category chart, and recommendations.
4. Download the text report.
5. Open Results Dashboard and show the saved submission.
6. If approved, submit a post-test with the same ID and explain the comparison.

## Important
Demo data is not research evidence. For actual data gathering, obtain project-guide approval,
explain the activity to participants, collect informed consent, use anonymous IDs, and record
only the minimum data required. Never enter names, contact details, passwords, or roll numbers.

## Suggested testing
- Try all correct answers: score should be 100%.
- Try all incorrect answers: score should be 0%.
- Leave one answer blank: submission should be blocked.
- Use a category score below 70%: relevant recommendations should appear.
- Submit pre and post scores under the same anonymous ID: paired comparison should appear.
- Run `pytest -q` for automated tests.
